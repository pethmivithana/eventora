                    EVENTORA - QUICK REFERENCE GUIDE

🚀 FASTEST WAY TO GET RUNNING (Copy & Paste):

1. Install dependencies:
   $ flutter pub get

2. Setup Firebase (auto-generates firebase_options.dart):
   $ dart pub global activate flutterfire_cli
   $ flutterfire configure

3. Run the app:
   $ flutter run

================================================================================
                         ESSENTIAL COMMANDS
================================================================================

Setup Commands:
  flutter pub get                  → Install all dependencies
  flutter pub upgrade              → Update all dependencies
  flutterfire configure            → Setup Firebase credentials

Running:
  flutter run                      → Run on default device
  flutter run -d emulator-5554     → Run on Android emulator
  flutter run -d iPhone14          → Run on iOS simulator
  flutter devices                  → List all connected devices

Debugging & Analysis:
  flutter analyze                  → Find code issues
  flutter clean                    → Clean build artifacts
  flutter format lib/              → Auto-format Dart code
  flutter pub outdated             → Check for outdated packages

================================================================================
                           COMMON ISSUES
================================================================================

"firebase_options.dart not found"
  → Run: flutterfire configure

"Pod install errors" (iOS)
  → Run: cd ios && rm -rf Pods Podfile.lock && cd .. && flutter pub get

"Device not found"
  → Run: flutter devices
  → Start emulator: emulator -avd Pixel_4_API_30

"Permission errors"
  → Run: flutter clean && flutter pub get && flutter run

"Dependency conflicts"
  → Run: flutter pub upgrade && flutter clean
