OPTION 1: AUTOMATIC SETUP (Recommended)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Install FlutterFire CLI
  $ dart pub global activate flutterfire_cli

Step 2: Configure (auto-generates firebase_options.dart)
  $ flutterfire configure
  
  When prompted:
    • Select your Firebase project
    • Choose Android & iOS platforms
    • Tool updates firebase_options.dart automatically

Step 3: Get Dependencies
  $ flutter pub get

Step 4: Run
  $ flutter run


OPTION 2: MANUAL SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Create Firebase Project
  Visit: https://console.firebase.google.com
  Create new project called "eventora"

Step 2: Get Credentials
  For Android:
    • Settings → "eventora (Android)"
    • Copy: apiKey, appId, messagingSenderId, projectId, storageBucket

  For iOS:
    • Settings → "eventora (iOS)"
    • Copy: Same as Android + iosBundleId

Step 3: Update File
  Open: lib/firebase_options.dart
  Replace placeholder values with your credentials

Step 4: Get Dependencies
  $ flutter pub get

Step 5: Run
  $ flutter run

╔════════════════════════════════════════════════════════════════════════════╗
║                         TROUBLESHOOTING                                    ║
╚════════════════════════════════════════════════════════════════════════════╝

  Problem: "firebase_options.dart error"
  Solution: Run → flutterfire configure

  Problem: "Device not found"
  Solution: 
    • flutter devices (to list)
    • Start emulator: emulator -avd Pixel_4_API_30
    • Or connect real device via USB

  Problem: "Pod install failed" (iOS)
  Solution:
    $ cd ios
    $ rm -rf Pods Podfile.lock
    $ cd ..
    $ flutter pub get
    $ flutter run

  Problem: "Dependency conflicts"
  Solution:
    $ flutter pub upgrade
    $ flutter clean
    $ flutter pub get
    $ flutter run

  For more issues: See README_SETUP.md
